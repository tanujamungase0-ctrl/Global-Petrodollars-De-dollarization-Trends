# 📊 Global Petrodollar & De-Dollarization Trends Analysis

## 📌 Project Overview
This project analyzes global petrodollar flows, oil production, crude oil prices, foreign exchange trends, and de-dollarization activities using Machine Learning techniques. The objective is to predict Brent Crude Oil prices and identify the key factors influencing global energy markets.

## 🎯 Objectives
- Analyze global oil production and trade patterns.
- Study OPEC quotas and major market events.
- Examine petrodollar recycling and sovereign wealth fund trends.
- Analyze de-dollarization indicators.
- Predict Brent Crude Oil prices using Machine Learning.

## 📂 Dataset
The project uses the following datasets:

- petrodollar_1_oil_production_trade.csv
- petrodollar_2_opec_quotas_events.csv
- petrodollar_3_recycling_swf.csv
- petrodollar_4_dedollarization.csv
- petrodollar_5_daily_prices_fx.csv
